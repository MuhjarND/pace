# Alternatif desain PACE

Tiga arah desain beranda untuk ditinjau pengguna. **Belum dipilih dan tidak mengganti desain aktif.** Dibuat dengan Built-in Image Gen. Prompt lengkap tersimpan di prompts.json.

| Pilihan | Gaya | Fokus |
|---|---|---|
| A | Institusional bersih | Ilustrasi arsitektur, susunan editorial, form wilayah horizontal, layanan berupa tautan terbuka |
| B | Hangat dan ramah | Ilustrasi interaksi masyarakat dan PTSP, form vertikal di samping, pintasan bergambar |
| C | Ringkas fokus pencarian | Form dua kolom sebagai pusat, ilustrasi kecil, layanan sebagai daftar |

Pratinjau: [A](a-institusional.png), [B](b-ramah.png), [C](c-ringkas.png). Semua berukuran 1487 × 1058 piksel. Header fixed ditetapkan sebagai perilaku desain; gambar statis tidak menguji perilaku tersebut.

Semua mempertahankan identitas PACE PTA Papua Barat, putih/oranye/kuning/hitam, header tetap dengan lima kanal, empat dropdown pencarian wilayah, konsultasi tanpa akun, dan footer identitas tanpa baris wilayah. Tidak mengembalikan rel menu kartu tambahan pada halaman interior.

Gambar merupakan konsep visual, bukan screenshot implementasi. Native select, interaksi mobile, validasi, izin dan data server harus mengikuti pemilik aplikasi saat desain pilihan diterapkan. Tidak ada perubahan kode runtime, database atau pengiriman WhatsApp pada tahap review ini.

Setelah pengguna memilih arah, rincian halaman layanan dan responsivitas mengikuti arah tersebut; konsep lain tetap sebagai alternatif historis.
