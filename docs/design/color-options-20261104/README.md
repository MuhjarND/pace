# Alternatif warna PACE

Tahap review warna, belum disetujui atau diterapkan. Ketiga gambar menggunakan komposisi konsep B sebelumnya untuk perbandingan palet yang lebih jelas. Pemilihan B sebagai acuan perbandingan tidak berarti pengguna sudah menyetujui susunan B.

| Pilihan | Utama | Pendamping | Karakter |
|---|---|---|---|
| D — Biru dan toska | #1D4ED8 | #0D9488 | Tenang, profesional |
| E — Hijau dan emas | #15803D | #D6A526 | Institusional, hangat |
| F — Ungu dan coral | #6D28D9 | #F97360 | Ekspresif, kontemporer |

Latar utama dan formulir tetap putih. Bentuk logo PACE, identitas institusi, teks, empat dropdown wilayah dan empat kanal layanan dipertahankan. Warna ilustrasi mengikuti masing-masing palet, dengan kulit/rambut dan material netral tetap alami. Tombol berwarna gelap menggunakan teks putih.

Gambar dibuat dengan Built-in Image Gen, bukan screenshot implementasi. Brief lengkap ada di prompts.json. Tidak mengubah DESIGN.md aktif, CSS runtime, database atau konfigurasi aplikasi. Header fixed dan perilaku mobile tetap menjadi persyaratan saat konsep yang dipilih nanti diterapkan.
